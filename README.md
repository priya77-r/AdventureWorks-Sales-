AdventureWorks Sales Analysis

An analysis of the AdventureWorks sales dataset in Power BI, using a data model with linked tables and DAX measures to explore key sales figures.

Project Overview

The AdventureWorks dataset stores sales information across several related tables. This project connects those tables in a proper data model and uses DAX measures to calculate and explore key sales metrics, so that results stay accurate when analysis spans more than one table.

What I Did
Analyzed the AdventureWorks sales dataset in Power BI to understand key sales metrics
Built a data model with defined relationships between the sales tables
Wrote DAX measures to calculate and explore key sales figures across the linked tables
Tools Used
Power BI for data modeling and analysis
DAX (Data Analysis Expressions) for measures and calculations
